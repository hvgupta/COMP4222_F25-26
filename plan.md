## Experimentation Plan

### Project Context
- `src/train.py` trains the `TwoTowerSAGE` model on graph-structured market data generated by `src/graph_builder.py`.
- Key knobs live across graph construction, model architecture, and trainer configuration. This document consolidates them and explains how to explore their effect with the new sweep script.

---

### Hyperparameters in the Codebase

**Graph / Data Pipeline (`src/graph_builder.py`)**
- `WINDOW_SIZE = 5`: trading days in each rolling correlation window.
- `CORRELATION_THRESHOLD = 0.8`: minimum absolute correlation used to create an edge.
- `START_YEAR = 2020`, `END_YEAR = 2025`: historical range pulled from SEC/Wikipedia sources.
- `train_frac = 0.8`: fraction of all `(source, target)` permutations kept for training at each date.
- `rolling_corr.abs()` and permutation sampling: determines sparsity/density of edge sets and pair counts.
- StandardScaler applied to all numeric features (except `PCT-1` and one-hot sectors) with clipping to ±5σ; persisted in `feature_scaler.pkl`.

**Model Architecture (`src/model.py`)**
- `hidden_dim = 64`, `out_dim = 32`: widths of stacked `SAGEConv` blocks per tower.
- `dropout = 0.3`: applied after first convolution in each tower.
- `embed_l2_reg = 1e-4`: weight of embedding regularization term.
- `normalize_embeddings = True`: L2-normalize node embeddings before interactions.
- `output_scale = 0.05`: learnable scalar limiting prediction range after `tanh`.

**Trainer (`src/train.py`)**
- `num_epoch = 100` (default in `main`), configurable per run.
- `learning_rate = 0.001` using Adam (instability noted for higher lr).
- `batch_size = 128` over sampled `(src_idx, tgt_idx)` pairs.
- `criterion = HuberLoss(delta=0.05)`.
- Gradient clipping at `max_norm = 1.0`.
- Device selection `cuda` if available; falls back to `cpu`.
- Per-epoch metrics (avg loss, batch count, graphs processed) are recorded in `TrainingSummary`.

---

### Hyperparameter Sweep Script
- **Path:** `scripts/hparam_search.py`
- **What it does:** performs a grid search over graph, trainer, and model parameters; each run writes:
  - `experiments/hparam_runs/run_<id>/history.json` (config + per-epoch metrics for reporting),
  - `experiments/hparam_runs/summary.csv` (aggregated table of all runs for quick comparison).
- **Default search space:** varies `window_size`, `corr_threshold`, `learning_rate`, `batch_size`, `hidden_dim`, `dropout`, `output_scale`, etc. You can override via `--search-space custom_space.json`.
- **Usage example:**
  ```bash
  python scripts/hparam_search.py --max-combos 4 --notes "lr/batch sanity check"
  ```
  After completion, inspect `summary.csv` for the effective tuples (lowest `best_loss`) and cite `history.json` files in the report for training curves and intermediate diagnostics.
